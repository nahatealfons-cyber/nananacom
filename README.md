# osint-recon-bot

Telegram-бот для разведки инфраструктуры (IP/ASN) в рамках **авторизованных**
pentest / red-team engagement'ов. Источник данных — [Shodan InternetDB](https://internetdb.shodan.io/),
бесплатный публичный API, который отдаёт уже собранные пассивные данные по IP
(открытые порты, баннеры/CPE, известные CVE, связанные hostnames). Сам бот
**не сканирует** цели и не трогает ничего, кроме как делает один HTTP GET к
InternetDB — активного взаимодействия с инфраструктурой цели нет.

## Важно: только для авторизованного использования

- Бот создавался для recon-этапа pentest/red-team, где есть подписанный
  scope/rules of engagement.
- Бот **не собирает персональные данные о людях** — только публичные данные
  об IP-инфраструктуре (хосты/порты/CVE). Это не инструмент для доксинга
  конкретных людей, и использовать его для этого не нужно — и не стоит.
- Перед первым /lookup каждый пользователь бота обязан один раз выполнить
  `/scope <текст>`, описав, в рамках какого engagement/проекта он работает.
  Это пишется в `audit.log` вместе с timestamp и user_id — простой
  accountability-механизм, а не защита от злоупотребления как таковая.
- Используйте бота только там, где у вас есть письменное разрешение
  (договор на pentest, bug bounty scope, собственная инфраструктура и т.п.).
  Ответственность за законность использования полностью на операторе бота.

## Установка

```bash
cd osint_bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN
python bot.py
```

## Команды

- `/start`, `/help` — краткая справка.
- `/scope <описание>` — зафиксировать, в рамках какого engagement вы работаете.
  Обязательно перед `/lookup`.
- `/lookup <ip-или-домен>` — показать данные InternetDB: открытые порты,
  CPE/баннеры, связанные CVE, hostnames, теги.

## Структура

```
osint_bot/
  bot.py              # точка входа, регистрация хендлеров
  config.py           # загрузка токена/настроек из .env
  osint/
    internetdb.py     # клиент Shodan InternetDB + резолв домена в IP
  audit.py            # запись /scope и /lookup в audit.log
  requirements.txt
  .env.example
```

## Расширение

Добавить WHOIS/DNS/crt.sh или другие пассивные источники — отдельные модули
в `osint/`, зарегистрированные как новые команды в `bot.py`, по той же схеме
(требование `/scope`, запись в audit-лог, только пассивные источники без
активного взаимодействия с целью).
